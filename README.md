$DevConverter
O $DevConverter é uma aplicação web simples e elegante para conversão de valores em Real (BRL) para moedas estrangeiras (Dólar e Euro). 
O projeto foca em uma experiência de usuário limpa, com validações de formulário e feedback visual animado.
FuncionalidadesConversão de Moedas: Converte valores de Real (R$) para Dólar (USD) e Euro (EUR).

Validação de Dados: Impede o envio de valores vazios ou negativos.
Formatação Automática: Utiliza a API Intl.NumberFormat para exibir os valores nos padrões monetários internacionais.
Feedback Visual: O resultado aparece na tela com uma animação de deslize (Y-axis) e ícones dinâmicos.
Limpeza de Campos: Os campos de entrada são resetados automaticamente após cada conversão.

Tecnologias UtilizadasHTML5: Estruturação semântica e formulários.CSS3: 
Estilização modularizada (arquivos separados para header, footer, reset e styles).
JavaScript (ES6):Manipulação de eventos (Submit).Lógica matemática para conversão.
Web Animations API: Utilizada na função animateResult() para o efeito de surgimento do valor.
Google Fonts: Utilização da fonte Poppins para um design moderno.
